# Whitespace M5 maintenance

Whitespace maintains this release line for Municipio 6.x installations.
The original Composer name, plugin directory, namespaces and settings remain
compatible with existing installations. The original MIT license is retained.

Releases start from the deployed upstream version and preserve its built
assets. Applicable MCT search patches are included in the maintenance release.
The fourth version component identifies Whitespace maintenance releases.
Upstream version upgrades require a separate compatibility review.

Release tags are published from `maintenance/m5`; upstream release workflows
must not generate releases for this branch.
